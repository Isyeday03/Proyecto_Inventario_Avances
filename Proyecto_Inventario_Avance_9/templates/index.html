Bienvenido al sistema

Este proyecto permite organizar de forma sencilla la información principal de un inventario. En este avance se incorporó Flask para gestionar las rutas, Jinja2 para reutilizar la estructura HTML y Bootstrap para conservar un diseño adaptable a computadoras, tablets y teléfonos.
