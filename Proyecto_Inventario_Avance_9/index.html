Página frontend del proyecto

Esta versión estática permite mantener visible la interfaz del proyecto mediante GitHub Pages. La versión desarrollada con Python, Flask y Jinja2 se encuentra en el repositorio y debe ejecutarse localmente.

Para probar las rutas Flask se debe ejecutar python app.py y abrir http://127.0.0.1:5000.
