Proyecto Integrador - Semana 14

En este avance se incorporó un sistema de autenticación de usuarios integrado con Flask y PostgreSQL.

El sistema permite registrar usuarios, proteger sus contraseñas mediante hash, iniciar y cerrar sesión, identificar al usuario autenticado y restringir el acceso a las páginas administrativas.

Importante: GitHub Pages muestra únicamente la presentación visual del proyecto. El sistema real de autenticación, Flask y PostgreSQL debe ejecutarse localmente mediante:

python app.py
http://127.0.0.1:5000
