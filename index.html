PostgreSQL + Flask + CRUD

Proyecto Integrador - Semana 13

Durante este avance se integró la aplicación Flask con una base de datos relacional PostgreSQL para gestionar de forma persistente la información del sistema.

El módulo de Productos implementa las operaciones principales de gestión de datos mediante consultas SQL parametrizadas.

Aplicación Flask: para probar todas las funcionalidades debe ejecutarse localmente mediante python app.py y acceder a http://127.0.0.1:5000.

Funcionalidades incorporadas

✅ Registro de productos
✅ Listado de productos
✅ Modificación de productos
✅ Eliminación de productos
✅ Validaciones Flask-WTF
✅ Protección CSRF
✅ Persistencia con PostgreSQL
✅ Relación Productos - Proveedores
✅ Consultas SELECT, INSERT, UPDATE y DELETE
